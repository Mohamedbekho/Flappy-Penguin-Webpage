# CSS Penguin

An animated CSS illustration of a penguin set against a winter mountain landscape, built to explore advanced CSS positioning, transformations, and keyframe animations[cite: 5, 6].

## Features

* **CSS Animations & Transforms:** Features a custom waving arm animation using `@keyframes` and interactive scaling effects on click[cite: 5].
* **Layered Scenery:** Utilizes skew, rotation, and `z-index` stacking to build a depth-oriented background with mountains, a sun, and ground gradients[cite: 5, 6].
* **Pure CSS Artwork:** Shapes the penguin's head, body, beak, eyes, and clothing entirely through HTML structural elements and precise CSS border-radius and linear gradients[cite: 5, 6].

## Technologies Used

* **HTML5**[cite: 6]
* **CSS3 (Animations, Transforms & Gradients)**[cite: 5]
